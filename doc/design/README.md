# Design guides

These guides brief Claude Design, or any designer, on a redesign of Ascent. Read them in order:

1. [The product](01-product.md): what Ascent is, who it is for, and the ideas every screen has to make clear.
2. [The screens](02-screens.md): each screen to redesign, what it shows today, and what it has to show.
3. [The brand](03-brand.md): the name, the mark, the palette, the type, the icons and the voice, and what is open to change.
4. [From design to code](04-implementation.md): how a design becomes Phlex components and the four-layer CSS, and what a handoff should include.

The guides describe the app as of October 2026, on the `voting-flow` branch. When the code and a guide disagree, the code is right and the guide needs updating.
